Design Inspiration

Inspired by the live set of Colorless Light, the installation turns vocal crescendos into a swirling nebula. A 512-point FFT isolates the mid-frequency band between 500 Hz and 4 kHz, compares it with low and high background energy, and drives the particle field via the vocal-to-backtrack ratio.

"Sound energy becomes a visible galaxy. Stronger choruses summon more comet visitors and blaze a brighter core."
Core Algorithms

1. Vocal Chorus Detection

  • 512-point FFT evaluates vocal energy between 500-4000 Hz versus low/high background energy
  • Weighted score blends vocalRatio, vocalBoost, and volumeFactor
  • When chorusScore > 0.6 and vocalRatio > 1.2, the chorus state is latched for 60 frames

2. Particle & Core Dynamics

  • Center pull: CENTER_PULL plus logarithmic distance creates the vortex core
  • Ripple system: Beats spawn Ripple particles that radiate circular pulses
  • Comet visitor: Chorus phases inject Comet entities with elongated tails
  • Dynamic population: Quiet baseline of 600, chorus peaks at 2000+, adapting to CHORUS_LEVEL

3. Bloom Post-Processing

  • Threshold pass extracts highlights with luminance > 0.72
  • 8-tap Gaussian blur with independent horizontal and vertical blurRadius
  • Custom composite shader adds the bloom layer to the base render
// Colorless Light: chorus detection snippet (Final.pde)
if (fft != null) {
  fft.analyze(spectrum);

  int vocalStart = (int)(500 / freqPerBin);
  int vocalEnd   = (int)(4000 / freqPerBin);

  vocalEnergy = 0;
  for (int i = vocalStart; i < vocalEnd; i++) {
    vocalEnergy += spectrum[i];
  }
  vocalAvg = lerp(vocalAvg, vocalEnergy, 0.01);

  backingEnergy = 0;
  for (int i = 0; i < vocalStart; i++) backingEnergy += spectrum[i];
  for (int i = vocalEnd; i < spectrum.length / 2; i++) backingEnergy += spectrum[i];
  backingAvg = lerp(backingAvg, backingEnergy, 0.01);

  vocalRatio = backingAvg > 0.001 ? vocalEnergy / max(backingAvg, 0.001) : 0;

  float chorusScore = 0.5 * vocalBoost + 0.3 * volumeFactor
                       + 0.2 * constrain(vocalRatio - 1.0, 0, 1);

  if (chorusScore > 0.6 && vocalRatio > 1.2) {
    chorusHoldFrames = CHORUS_HOLD;
  }
}

Design Inspiration

Inside the AudioPress sketch, breath becomes both input and tempo. The system watches a 20-frame rolling microphone average; whenever the amplitude surpasses 1.2x the mean, it emits a set of classic ratio rectangles accompanied by wind particles.

"Breath turns into rectangles and primary colors, translating unconscious rhythms into Mondrian order."
Core Algorithms

1. Breath Detection

  • Sample amplitude in real time and maintain a 20-frame history queue
  • Breathing triggers when current level > breathThreshold and > rolling average x 1.2
  • Breath strength maps to 0.2 - 2.0 with gentle decay

2. Composition & Color

  • Golden ratio φ plus rule-of-thirds anchors form compositionNodes
  • 80% chance to spawn golden rectangles, 20% to introduce squares or slim strips
  • Authentic Mondrian palette: red, yellow, blue, off-white, cream, and restrained black

3. Dynamic Expression

  • Fresh blocks inherit damping and snap toward a 20 px grid for classic layouts
  • Breathing simultaneously spawns WindParticle trails to visualize airflow
  • Keyboard shortcuts: S save poster, M restart mic, R reset composition
// Breath-driven block generation (AudioPress.pde)
void generateClassicBreathBlocks() {
  int numBlocks = (int)(breathStrength * 3);

  for (int i = 0; i < numBlocks; i++) {
    float x = random(width);
    float y = random(height);

    x = constrain(x, width * 0.05, width * 0.95);
    y = constrain(y, height * 0.05, height * 0.95);

    float maxBlockSize = min(width, height) / 4.0;
    float randomSize = random(25, maxBlockSize);
    float baseSize = map(breathStrength, 0, 2.5,
                                  randomSize * 0.5, randomSize);

    color c = getClassicMondrianColor();
    ColoredBlock block = new ColoredBlock(x, y, baseSize, baseSize / goldenRatio, c, 0);

    float blowForce = map(breathStrength, 0, 2.5, 0.2, 2.0);
    block.velocity.add(random(-blowForce * 0.3, blowForce * 0.3),
                         random(blowForce * 0.1, blowForce * 0.8));

    blocks.add(block);
  }
}
