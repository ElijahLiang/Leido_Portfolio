智能 NPC 研究之旅：面向 3D 世界的具身智能

从脚本式 AI 转向基于感知的认知架构

VLM + LLM 架构 观察 → 思考 → 行动循环 🏛️ 博物馆应用场景 📄 论文草稿已完成

这个项目使用视觉语言模型（VLM）理解第一人称视觉输入，再由大语言模型（LLM） 进行自然语言推理与决策。它让 NPC 不再依赖预设脚本，而是基于对场景的理解进行行动， 从而生成更自然、更不可预设的行为。

智能 NPC：VLM 驱动的虚拟讲解员

📍 无锡鸿山博物馆虚拟展厅

从实验原型走向真实应用：智能 NPC 成为虚拟博物馆中的讲解员。

这是一套由视觉语言模型（VLM）驱动的具身导览系统：它不再依赖预设对话，而是能够“看见”展品， 根据游客的位置和问题实时生成讲解，并自主回应场景变化。

⚡ 技术特征

  • VLM 场景感知 — AI 可以“看见”并理解展品
  • LLM 推理 — 基于视觉理解生成自然讲解
  • 自主导航 — 引导游客穿行于展厅
  • 情感交互 — 以更有温度和人格感的方式回应

🚀 未来方向

  • 用户体验路径记录与分析

📓 开发日志

这个项目记录了我进入具身 AI 的研究过程。2025 年 11 月，我开始尝试在 Unity 中用 LLM 驱动 NPC。最初我依赖 Raycast 等启发式方法来模拟感知，但它很快暴露出导航不稳定、缺乏真实空间理解等问题。我也短暂尝试过 ML-Agents，却发现强化学习更像是在训练一个“被条件化的主体”，它能完成任务，却不具备我想要的泛化与理解能力。

真正的突破来自视觉语言模型（VLM）的接入。它让 NPC 第一次能够真正“看见”。到 2026 年 1 月，我完成了一个端到端循环：一个能够感知、推理，并以具体动作和情绪进行回应的智能体。虽然目前的动作层仍受硬件和实时性限制，需要部分脚本驱动，但这个原型验证了核心架构，也为后续世界模型与 Sim2Real 方向奠定基础。

📄 论文摘要

本文介绍一套面向 3D 交互环境的具身 AI 智能体框架，尤其聚焦于非玩家角色（NPC）。 系统从依赖射线检测、预设行为树等结构化数据的传统程序式 AI，转向一种 由感知驱动的认知架构。论文说明了系统结构、观察-思考-行动循环的核心组件， 以及自主行动与玩家交互两种模式下的数据流。这个框架是通向更动态、更可信、 更具智能感的虚拟世界智能体的重要一步。

January 2026

I've updated another version of the embodied NPC — this time with facial expressions, walking animations, and an avatar that can interact with players. Although the models and scenes are still rough and there are some bugs to fix, this is a significant step forward. Implementing embodiment in 3D environments, walking mechanics, and database construction proved far more challenging than expected. However, the basic requirements are now in place, and future development will focus on game design in new environments to support the Open Theatre Game Theory.

Navigation

Memory

Triple memory: env / dialogue / goals

DialogueSystem.cs

Multimodal dialogue gateway

  • Capture player text/voice inputs
  • Call vision.GetVisualDesc() to inject live scene narration
  • Assemble the system prompt with mission + safety guardrails
LLMBrain.cs

Reasoning engine · THOUGHT/ACTION

  • Package environment state, short-term memory, and persona
  • Guide the model to emit THOUGHT/ACTION/BELIEF templates
  • Invoke ExternalLLM.Chat() while tracking token budget
ExternalLLM.cs

Model abstraction layer

  • Wrap DeepSeek, GLM, and open APIs for hot swapping
  • Unify JSON requests, retries, and rate limiting
  • Return raw text responses for downstream parsing
YangguangAI.cs

Behavior orchestration

  • Update current targets, behavior modes, and state machine
  • Command NavMeshAgent with anti-stuck + exploration modes
  • Track visited objects to avoid redundant searches
YangguangVision.cs

Vision loop (text-based)

  • OverlapSphere + FOV filtering for 3D detections
  • Raycast occlusion checks to build the visible list
  • Convert world state into natural language for DialogueSystem
