Yangguang: VLM-Embodied AI Docent

📍 Wuxi Hongshan Museum Virtual Exhibition

From experimental prototype to real-world application — Yangguang becomes an intelligent docent in a virtual museum.

This is the first embodied tour guide system powered by Vision-Language Models (VLM): instead of relying on pre-scripted dialogues, the AI "sees" the exhibits, autonomously generates explanations, and responds in real-time based on visitor location and questions.

📓 Development Journal

This project represents a solitary yet enlightening journey into Embodied AI. Starting in November 2025, I attempted to drive an NPC using LLMs within Unity. My initial approach relied on heuristic hacks like Raycast for perception, which resulted in poor navigation and a lack of true spatial awareness. I briefly detoured into ML-Agents, only to realize that reinforcement learning created a "conditioned subject"—functional but incapable of the generalization I sought.

The breakthrough came in December with the integration of Vision-Language Models (VLM), granting the agent the ability to truly "see." Following a brief academic hiatus, in January 2026, I successfully achieved an end-to-end loop: an agent that perceives, reasons, and reacts with specific behaviors and emotions. While hardware constraints currently necessitate a script-driven action layer (preventing a full VLA implementation), this prototype validates the core architecture and paves the way for future explorations in World Models and Sim2Real robotics.

📄 Paper Abstract

This paper introduces Yangguang, a novel framework for developing embodied AI agents, specifically Non-Player Characters (NPCs), within interactive 3D environments. The system marks a paradigm shift from traditional, programmatic AI—which relies on structured data like ray-casting and predefined behavior trees—to a perception-driven cognitive architecture. We detail the system's architecture, the core components of its Observe-Think-Act loop, and the data flow for both autonomous operation and player interaction. The Yangguang framework represents a significant step towards creating more dynamic, believable, and truly intelligent agents in virtual worlds.

DialogueSystem.cs

Multimodal dialogue gateway

  • Capture player text/voice inputs
  • Call vision.GetVisualDesc() to inject live scene narration
  • Assemble the system prompt with mission + safety guardrails
LLMBrain.cs

Reasoning engine · THOUGHT/ACTION

  • Package environment state, short-term memory, and persona
  • Guide the model to emit THOUGHT/ACTION/BELIEF templates
  • Invoke ExternalLLM.Chat() while tracking token budget
ExternalLLM.cs

Model abstraction layer

  • Wrap DeepSeek, GLM, and open APIs for hot swapping
  • Unify JSON requests, retries, and rate limiting
  • Return raw text responses for downstream parsing
YangguangAI.cs

Behavior orchestration

  • Update current targets, behavior modes, and state machine
  • Command NavMeshAgent with anti-stuck + exploration modes
  • Track visited objects to avoid redundant searches
YangguangVision.cs

Vision loop (text-based)

  • OverlapSphere + FOV filtering for 3D detections
  • Raycast occlusion checks to build the visible list
  • Convert world state into natural language for DialogueSystem
