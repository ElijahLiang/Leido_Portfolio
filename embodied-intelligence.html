Embodied AI · VLM-Driven Framework

Yangguang: Embodied Intelligence for 3D Worlds

A paradigm shift from scripted AI to perception-driven cognition

VLM + LLM Architecture Observe → Think → Act Loop 📄 arXiv Draft Ready

Yangguang leverages a Vision-Language Model (VLM) to interpret first-person visual input, enabling a Large Language Model (LLM) to perform reasoning and decision-making in natural language. This approach allows the agent to operate based on genuine understanding of its visual surroundings, leading to emergent, unscripted behaviors.

📄 Paper Abstract

This paper introduces Yangguang, a novel framework for developing embodied AI agents, specifically Non-Player Characters (NPCs), within interactive 3D environments. The system marks a paradigm shift from traditional, programmatic AI—which relies on structured data like ray-casting and predefined behavior trees—to a perception-driven cognitive architecture. We detail the system's architecture, the core components of its Observe-Think-Act loop, and the data flow for both autonomous operation and player interaction. The Yangguang framework represents a significant step towards creating more dynamic, believable, and truly intelligent agents in virtual worlds.

DialogueSystem.cs

Multimodal dialogue gateway

  • Capture player text/voice inputs
  • Call vision.GetVisualDesc() to inject live scene narration
  • Assemble the system prompt with mission + safety guardrails
LLMBrain.cs

Reasoning engine · THOUGHT/ACTION

  • Package environment state, short-term memory, and persona
  • Guide the model to emit THOUGHT/ACTION/BELIEF templates
  • Invoke ExternalLLM.Chat() while tracking token budget
ExternalLLM.cs

Model abstraction layer

  • Wrap DeepSeek, GLM, and open APIs for hot swapping
  • Unify JSON requests, retries, and rate limiting
  • Return raw text responses for downstream parsing
YangguangAI.cs

Behavior orchestration

  • Update current targets, behavior modes, and state machine
  • Command NavMeshAgent with anti-stuck + exploration modes
  • Track visited objects to avoid redundant searches
YangguangVision.cs

Vision loop (text-based)

  • OverlapSphere + FOV filtering for 3D detections
  • Raycast occlusion checks to build the visible list
  • Convert world state into natural language for DialogueSystem
